# PulseCam iOS 原生工程

此目录为 iOS 17+ 的 SwiftUI/Xcode 源码，需 macOS + Xcode 16+ 打开 `PulseCam.xcodeproj`。在真机运行时需设置自己的签名 Team 并授予摄像头权限；Windows 上无法编译或验证。HealthKit/App Groups 还需检查签名能力。未提供 TestFlight。

相机路径使用 Vision 面部 ROI、绿色通道时序、按帧时间戳重采样、滤波和 FFT 心率估计、峰间期短时程 HRV 指标；没有稳定面部/足够帧数/足够信号质量时不保存结果。30 秒只用于参考，不应将 LF/HF 或压力分数理解为临床指标。测量结果仅供日常自我观察，不能诊断疾病。

设置中的“模拟数据模式”运行合成信号来演示 UI 和分析管线。模拟结果会标注，且不会写入健康记录或 HealthKit。首页没有测量数据时显示“—”；没有睡眠记录时也显示“—”/“未记录”，不补造睡眠史。

当前工程仅有 App target。`Widgets/` 下的示例代码未构成可安装 Widget Extension；Siri 指令、Apple Watch 实时融合、预警通知、跨端同步和 StoreKit 正式购买也未交付。设置页隐藏了上述未接通开关，评审时不要把它们描述为已经上线的功能。

端侧语音仅在设备支持本地识别时启动；不支持时请使用文本输入。项目包含一些尚未经过真机数据集校验的启发式恢复/压力评分，不是经验证的医疗算法。算法与界面仍需在 macOS 真机上做编译、遮挡、低光和信号质量验证。
