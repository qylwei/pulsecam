# PulseCam · 非接触式心率健康监测

用普通摄像头做非接触心率监测：5 秒面部自检 → 15 秒心率估算 → 按需 60 秒深度检测，输出心率与短时 HRV（RMSSD / SDNN）。
独立开发。获中国高校计算机大赛移动应用端省级奖项。

> 诚实口径：心率算法目前仅在合成信号上验证，尚未做真人对照验证，不能用于诊断。
> 这个项目做扎实的是流程设计与数据质量门控，不是实测准确率。

## 它能做什么

- **5 秒自检**：面部、光照、姿态、稳定度检查，不产出任何生理指标。
- **15 秒估算**：心率估算，带置信度；质量不足直接拒测，不给假结果。
- **60 秒深测**：心率 + 短时 RMSSD / SDNN，标注“短时程参考”。
- **质量门控**：未测量的心率 / HRV / 呼吸显示为 `—`，不做默认值填充；缺失值不填充。
- **记录与回顾**：Web 端 PulseLog 可查看历史记录；AI 顾问默认用本地规则回答。

## 怎么跑起来（Web 端）

Windows：双击 `启动PulseLog.bat`，服务就绪后自动打开 `http://localhost:3100`。

macOS / Linux：

```bash
cd "01_Web全栈工程 (PulseLog)"
npm ci
sh start.sh
```

测试：

```bash
cd "01_Web全栈工程 (PulseLog)"
npm test
npm run validate
```

## 数据与隐私

- 本机记录保存在 `01_Web全栈工程 (PulseLog)/data/pulselog.db`，首次运行自动生成。
- 摄像头视频帧只在浏览器内存中取均值，不上传、不落盘。
- AI 默认使用本地规则；只有主动配置云端 Key 并提问时，才发送问题与近期记录摘要。

## 已知限制

- 心率算法仅在合成信号上验证，尚未完成真人与参考设备对照，不能用于诊断。
- 未配置云端 Key 时，AI 由本地规则回答，能力有限。
