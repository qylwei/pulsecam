# PulseCam Web 本机生活记录

Node.js 22+；在此目录执行 `npm ci`、`npm start`，浏览器打开 `http://localhost:3100`。Windows 也可在上级目录运行 `启动PulseLog.bat`；macOS/Linux 可运行 `sh start.sh`。运行 `npm test` 执行独立数据库的接口与信号测试；`npm run validate` 输出合成信号误差/拒测表。

Web 扫脸分为 5 秒自检（人脸/光照/姿态/稳定）、15 秒心率估算（不输出 HRV）、60 秒深测（合格时输出心率和短时 RMSSD/SDNN）。质量不足时拒测；前置摄像头需要浏览器授权，拒绝后仍可手动记录。指标标明手填、实测或推算，缺失值留空。呼吸放松练习仅记录主观评分，不推断心率变化。

`npm run validate` 在 48/72/90/110/150 bpm 的确定性合成 RGB 信号上测试三档噪声：48–110 bpm 的样本误差均低于 0.02 bpm；150 bpm 深测样本因峰间期质量门槛拒测。合成结果不等于真人准确率；尚未完成真人与参考设备的对照，也不能用于诊断。

本机服务的记录保存在 SQLite；纯静态托管另存于浏览器，两种模式不互通。摄像头视频帧只在浏览器处理、不上传。AI Key 仅保存在本机服务当前进程；主动云端提问时发送问题及近期记录摘要。静态模式不支持配置云端 Key；本地规则仍可回答。旧版磁盘配置文件若存在，需由用户自行核查清理。

HTTP 局域网扫码链接仅供界面预览；iOS 原生工程需要在 macOS/Xcode 真机环境独立运行。健康分数为生活记录的规则计算结果，不是医疗评估。
